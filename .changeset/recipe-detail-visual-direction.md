RecipeDetailPage now follows the recipe-detail visual direction. The hero image renders in an aspect-preserving frame: Thumbnail's hero measures the image's natural aspect ratio and clamps it to [0.75, 2.25] (4:3 before load), replacing the fixed 256px cover-crop frame — hosts with recipe imagery will see heroes shaped by their images. The overview gains three optional app-supplied props: `categoryLabel` and `totalTimeLabel` feed a sage metadata pill under the hero ("Category • 45 min • Serves 4", joined from whichever parts are present, alongside the existing servings label), and `cookingTipLabel` renders an italic hint line under the Start Cooking action. The title renders in a new serif `display` Text variant (3xl bold, verse family). Start Cooking sits on its own row — full-width on mobile, capped on web — with the print/share/edit actions on the row beneath. The Ingredients heading carries a new Feather `list` icon (SectionHeading gains an optional `icon` prop, and "list" joins the icon-name registry), ingredient rows lead with a checkbox box that checks when an ingredient is marked missing, and instructions render through StepList's new opt-in `numeral` presentation (a large accent numeral beside each step instead of the "Step N" eyebrow; the eyebrow stays the default for other consumers). RecipeImageView's loading skeleton now holds the hero's 4:3 fallback shape. Hosts adopt the new overview props by passing the labels; everything else renders without host changes.

Fidelity round (#721, Stephen's owner review): the page now renders in the visual direction's exact order — hero, metadata pill, serif title, description, Ingredients, Instructions, Start Cooking, then the centered italic tip line — and everything not in the direction image (the Servings/Prep/Cook stat band, the status badge and version selector, the servings stepper and scale pills, the print/share/edit/delete and tweak action rows, and the substitutions panel) renders below Start Cooking. The Warm Harvest page surface is the direction's warm cream (#FBF4E8) and its primary is the sampled burnt orange (#B13F13). The metadata pill is Badge's `success` tone restyled as a filled sage band (#5C614F) with white text. Start Cooking is a fully rounded pill, full width on every viewport (the earlier web width cap is removed). Ingredient rows use the unified checkbox treatment: an unfilled terracotta-outline box in both states with a terracotta check, and the row text never dims. Instructions in the `numeral` presentation are flat text rows — an orange numeral and period beside the body, with no card, border, or filled highlight. The page's story hero fixture is a real turkey photo cropped from the visual direction image, replacing the generated gradient placeholder.
