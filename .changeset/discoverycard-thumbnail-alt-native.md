DiscoveryCard: the card's thumbnail image is no longer exposed as an unlabeled accessibility element on native. The card previously rendered its own local image with an empty `alt`; React Native's Image turns any `alt` value into an accessible element carrying that label, so on native the thumbnail appeared in the accessibility tree as a focusable element with an empty name, inside a card whose name is its title and subtitle (verified against the Android accessibility tree, #349 — the card's native link grouping does not mask it, unlike the recipe-list rows). The card now renders its image through the shared Thumbnail component's row variant, whose decorative treatment is platform-split (empty `alt` on web, no `alt` on native, #339); the geometry is identical (64dp square, cover crop), the no-image placeholder block is unchanged, and no consumer changes are needed. On a @spudly/ui bump, re-check in Storybook: Components/DiscoveryCard's stories and the Pages/Eciperay/DiscoverPage stories render the cards as before, and a card with a thumbnail image keeps the image decorative — announced nowhere, with the card itself named by its title and subtitle.
