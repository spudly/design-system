RecipesPage: rework the row actions. **Breaking:** the `onRecipeDelete` prop is removed — a recipes list row no longer offers Delete at all; deleting a recipe lives on RecipeDetailPage (its `onDeletePress` chip), so consumers must stop passing the callback. The "Log cook" text button is also gone: `RecipesPageItem` gains an optional `rating` field (display rating 0–5, or null/absent when unrated), and the row's log-cook control is the rating itself — a rated recipe renders its five stars as the pressable that fires `onLogCookPress`, and an unrated recipe renders a single icon-only button (one unfilled star, no text) firing the same callback. Both states carry an accessibility label naming the log-cook action. The control renders inline inside the text block — in the subtitle's wrapping flow, immediately after the subtitle text — never as a flex item of the card row, so it cannot compete with the text column for the row's width (as a trailing row item it reproduced the #205 narrow-viewport failure: the title wrapping a character at a time while the control held its width at the row's edge).
