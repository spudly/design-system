Tag colors are now named design-system tokens instead of raw hex values. TagPill, ColorPickerField, TagsPage, and RecipeDetailPage take tag color names (indigo, red, orange, amber, lime, green, teal, cyan, blue, purple, pink, gray) and resolve each name through the active theme: Warm Harvest renders the familiar palette shades and Quiet Dawn renders its own cooler shades of the same names. The set is strict and enforced by TypeScript — every tag-color prop is typed with the exported `TagColorName` union, so passing a raw hex value is a compile error. TagsPage's `colorOptions` and ColorPickerField's `colors` take token names, ColorPickerField reports the selected name, and its swatch labels name the color ("Select color blue"). Tags stored with a legacy palette hex keep rendering in their color: the new exported `tagColorNameForHex` helper converts a stored hex to its token name at the data boundary (the legacy hexes are unchanged as the Warm Harvest values, so existing tags look the same in Eciperay). A stored color that is not one of the twelve palette hexes no longer renders as itself — it converts to the default name (`defaultTagColorName`, gray) — so changing a brand's palette only ever means editing the theme token values.
