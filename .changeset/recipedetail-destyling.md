RecipeDetailPage is rebuilt from shared components (#119, recipes-detail tranche): the page now composes a ScreenShell + Toolbar chrome over a ScrollRegion with PanelStack section panels, and consumes the shared components the #119 dedupe shipped — RatingsCard, StepList, MarkableRow, SuggestionPanel, TagList, SectionHeading, StatusBadge, PresetValueSelector, CenteredText — alongside this tranche's own NutritionPanel, CandidateList, LogEntryCard, and PanelStack. The page's earlier local copies of the deduped components are deleted. Following the dedupe's chip retirement, the page's chip-shaped actions render as Buttons: Edit / Edit draft / Tweak with AI in Button's href form, Tweak manually as a callback Button (the #248 mutation exemption), Delete and Abandon in the danger variant, Mark perfected in the secondary variant, and print/share as icon-only md Buttons through Button's icon slot. The servings/scale block keeps its props contract: servings stays the inline editable NumberStepper, and scale is the PresetValueSelector (preset buttons plus a Custom value that turns into a number input). The action status line renders as a centered hint line (CenteredText), and each section heading renders inside its panel, taking the panel's inset. Button's `grow` keeps a content-sized flex basis in both its button and link forms (flexGrow with flexBasis "auto", never flex: 1's zero basis), so a growing button in a wrapping row no longer collapses below its label on native. Rendering is otherwise unchanged apart from the canonical treatments the components own: the recipe description takes the body text treatment, and panel separations follow PanelStack's 16px rhythm. On a @spudly/ui bump, re-check in Storybook: Pages/RecipeDetailPage (Default, Ingredients, Instructions, CookHistory, CookLogFormOpen, Nutrition, Minimal, Loading) — the overview action row (Start Cooking grown, print/share square targets, Edit/Delete), the lifecycle button row on editable versions, the servings stepper and scale selector in Ingredients, and the status badge in the toolbar and overview.
