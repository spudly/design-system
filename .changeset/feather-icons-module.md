New icons module (`@spudly/ui/icons`): a FeatherIcon component that renders the official Feather SVG icon data with react-native-svg, typed by Feather name. The set covers home, book-open, users, plus, tag, user, coffee, alert-triangle, message-circle, printer, and share-2, and the module also carries the featherIconNames list and the tabIcons tab-bar mapping that previously lived in eciperay's packages/icons package. Icons render at a caller-chosen size and stroke color with Feather's 2px round-cap stroke treatment, identically on web and native.
