Fix password-field autocomplete hints on web: `TextField` now translates the React Native `autoComplete` values `password` and `password-new` to the HTML tokens `current-password` and `new-password` when it forwards the prop to the web input, so browsers and password managers recognize the password fields; native values pass through unchanged, and other values such as `email` and `username` pass through unchanged on both platforms. The auth forms keep passing the native values — only the rendered web attribute changes. This affects the password fields built on TextField in `SignInForm`, `SignUpForm`, `ResetPasswordForm`, and the sign-in/sign-up/reset pages that compose them. On a @spudly/ui bump, re-check on web: open the Sign in form (Storybook Components/SignInForm or Pages/SignInPage) and confirm the password input carries `autocomplete="current-password"`, open the Sign up and Reset password forms and confirm their password inputs carry `autocomplete="new-password"`, and confirm the Email field still carries `autocomplete="email"`; a password manager should offer to fill the current password on sign-in and to save a new password on sign-up/reset.
