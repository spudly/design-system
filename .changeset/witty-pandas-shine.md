Initial component library release. Adds the full Phase 1–3 component set (36 components): Text, TextField, SearchField, MultilineField, SelectField, CheckboxField, RadioOptionGroup, ToggleChipGroup, NumberStepper, StarRatingInput, ColorPickerField, ChecklistRow, Button, Card, SectionCard, Badge, EmptyState, InlineAlert, DismissibleBanner, Spinner, ProgressBar, StepDots, Divider, Tabs, ScreenContainer, FormScreenLayout, OptionCard, PrevNextNav, SecretRevealPanel, Avatar, StatCard, BlankWord, VerseText, Dialog, Toast, Switch. Also finalizes the token system: terracotta + teal brand ramps, Warm Harvest (Eciperay) and Quiet Dawn (Memorize) themes, serif font token, and WCAG AA-verified semantic color roles.
