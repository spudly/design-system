New IconButton component (Components/IconButton): a dedicated icon-only button for actions like print, share, add, and delete, replacing the ad-hoc Button + icon compositions hosts used to hand-roll (each with its own sizing, padding, and labeling). It takes a design-system icon component (PrintIcon, ShareIcon, … from `@spudly/ui/icons`), a press callback, and a REQUIRED `accessibilityLabel` — there is no visible text to name the button — in Button's four variants (primary, secondary [the default], ghost, danger) and three standard sizes whose square touch targets are 44px (sm), 48px (md), and 56px (lg), with the glyph (18/20/24px) inked in the same color the variant gives a text label in the active theme. Disabled dims the button, blocks presses, and announces the disabled state. On a @spudly/ui bump, re-check Components/IconButton in Storybook: every variant's glyph is clearly visible against its fill; the Sizes row grows sm → lg with the glyph centered in each square; PressCounter increments when the button is pressed (and via Enter/Space on web); Disabled does not respond; and the button is findable by its accessible name ("Print recipe") with no `accessibilitylabel` attribute in the DOM.
