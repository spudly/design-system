# Eciperay brand assets (#861)

The full asset set for the approved Eciperay mark ("Ecipe-ray":
terracotta sun and rays behind a sage recipe card with a cream E —
Warm Harvest palette, ported in `src/icons/BrandMark.tsx`, PR #887).
Generated from that component's exact geometry by
`tools/brand-assets/generate_eciperay_assets.py` — regenerate, never
hand-edit, so the assets cannot drift from the mark the design system
renders. The mark carries its own warm-paper field (#faf6f0), so the
icons below are the full composition, field included.

| File | Use |
| --- | --- |
| `eciperay-mark.svg` | The mark, with its paper field (source artwork) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Browser favicons |
| `apple-touch-icon-180.png` | iOS home-screen icon |
| `icon-192.png`, `icon-512.png` | PWA icons (full composition) |
| `app-icon.svg`, `app-icon-1024.png` | App / store icon: mark at 76% on the Warm Harvest paper field (#faf6f0) |
| `lockup-horizontal.svg` / `.png` | Mark + "Eciperay" wordmark to the right (Raleway SemiBold, ink #292019, transparent) |
| `lockup-stacked.svg` / `.png` | Mark above the wordmark, centred (same type treatment) |
